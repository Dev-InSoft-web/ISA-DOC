# Tickets (HTML de soporte)

Al diligenciar o actualizar entradas en `index.ts`, seguir la skill del proyecto:

**`.cursor/skills/diligenciar-tickets/SKILL.md`**

## Estructura

Metadatos en PG (`isa-doc/tickets/ticket`); cuerpos algorítmicos en `records/{clientesis|patyia}/{mes}/{día}/TK-*.ts`. Convenciones: **`docs/STORE.md`**, **`docs/LAYOUT.md`**, **`docs/CODE-FRAGMENTS.md`** (snippets sin comentarios).

## Resumen de redacción

Pasado impersonal, sin citar repositorios internos, códigos de ticket ni asesores en el texto visible; SQL en bosquejo corto en `cambiosBd`.
