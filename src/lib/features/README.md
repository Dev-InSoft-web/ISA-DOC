# Features

Dominios de producto. Cada carpeta puede tener subcapas numeradas (PatyIA) o plana (tickets).

| Feature | Uso en UI |
|---------|-----------|
| `bitacora/` | `/clientesis/bitacora` — diario ISA, temas, revisado |
| `patyia/` | `/patyia/*` — prompts, OpenAI, SQL Paty, bitácora Paty |
| `tickets/` | Visor HTML de TKs, assets Mermaid/charts |

No importar un feature desde otro salvo dependencia explícita documentada.
